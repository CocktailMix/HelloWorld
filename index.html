So kommt diese Seite zu dir

  1. Schreiben Die Seite besteht aus einfachen Textdateien: HTML für den Inhalt, CSS für das Aussehen.
  2. Speichern Die Dateien liegen in einem Repository bei GitHub. Jede Änderung ist dort eine eigene Version.
  3. Veröffentlichen GitHub Pages macht nach jeder Änderung aus dem Repository die fertige Website.
  4. Aufrufen Dein Browser fragt beim DNS nach der Adresse und lädt dann die Dateien von GitHub.
